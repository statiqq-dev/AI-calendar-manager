# AI Calendar Manager

AI-агент для управления календарём macOS на LangChain.

## Установка и запуск

1. Установите [uv](https://docs.astral.sh/uv/).
2. Установите [Ollama](https://ollama.com) и скачайте модель: `ollama pull qwen3:8b`.
3. Скопируйте `.env.example` в `.env` и при необходимости поменяйте значения.
4. Запустите: `uv run calendar-agent`.
